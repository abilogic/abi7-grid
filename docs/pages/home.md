## Why ABI7 Grid

- **Two source files.** `abi7-grid.js` and `abi7-grid.css`. No build step is required to use them, and there are no runtime dependencies.
- **Three layouts, one engine.** Masonry, Grid and Justified share one layout contract; your own layouts plug in through the Layout API.
- **Virtualization.** Only the visible cards (plus overscan) are in the DOM; DOM nodes are pooled and reused.
- **Plugins.** An isolated Plugin API with automatic cleanup. Seven plugins are included in `plugins/`.
- **Documented from the code.** The test suite checks that every public method, option and event is described, and that the examples run.
