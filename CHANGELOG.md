# Changelog

All notable changes to ABI7 Grid Community. The version numbers describe this repository only.

## 1.0.0 — Community Edition

First release of the public **ABI7 Grid Community** repository. The core was taken from the existing source (`abilogic/abi7-tmp`) without rewriting; changes to the core are limited to the header comments (license notice and authorship).

### Core
- Layouts: Masonry, Grid, Justified; Layout API.
- Virtualization with DOM Pool, adaptive overscan, Scroll Anchoring, `scrollToIndex`, pinned items, Dynamic Size Cache.
- Partial recalculation; Drag & Drop on Pointer Events; async loading with `AbortController`.
- Plugin API with isolation, compatibility checks and automatic cleanup.
- Two source files: `src/abi7-grid.js`, `src/abi7-grid.css`; minified files are generated by `npm run build:lib`.

### Plugins
- `selection`, `lightbox`, `layout-horizontal`, `connected-grids` (from the existing source).
- `hover-effects`, `reveal`, `transitions` (added in this repository; use only the existing Plugin API).

### Documentation and tooling
- English documentation site (`docs/`), internal architecture notes with diagrams, plugin tutorial, 25 runnable examples.
- License documents in `licenses/`.
- `tools/check.js`, GitHub Actions for validation and GitHub Pages.
- Tests: the existing suite (translated to English) plus the examples added here.
